## 2. Теоретическое обоснование

Бэкенд представляет собой серверную часть веб-приложения. Он принимает запросы от клиента, выполняет необходимую обработку и возвращает результат. В качестве клиента может выступать браузер, мобильное приложение или другая программа. Веб-приложения работают по клиент-серверной архитектуре: клиент отправляет HTTP-запрос, а сервер формирует HTTP-ответ.

Эндпоинт — это определённый адрес и HTTP-метод, по которому клиент обращается к серверу. В данной работе использовался метод GET, предназначенный для получения данных. Для создания серверного приложения использовалась платформа Node.js и веб-фреймворк Express.

Для передачи структурированных данных применялся формат JSON. JSON удобен для обмена данными между клиентом и сервером, так как имеет простую структуру и поддерживается большинством языков программирования. Для автоматического перезапуска сервера после изменения исходного кода использовался пакет `nodemon`.

# 6. Контрольные вопросы

## 1. Что такое клиент-серверная архитектура?

Клиент-серверная архитектура — это способ организации программной системы, при котором клиент отправляет запросы, а сервер принимает их, обрабатывает и возвращает ответы. Например, браузер является клиентом, а приложение на Node.js — сервером.

## 2. Какой протокол используется для общения клиента и сервера в вебе?

Для взаимодействия клиента и веб-сервера используется протокол HTTP или его защищённая версия HTTPS.

## 3. Что такое эндпоинт?

Эндпоинт — это конкретный адрес API вместе с HTTP-методом. Например:

```text
GET /api/orders
```

Здесь `/api/orders` является маршрутом, по которому клиент получает список заказов.

## 4. Какую структуру имеет HTTP-запрос и HTTP-ответ? Что такое код состояния?

HTTP-запрос обычно содержит HTTP-метод, URL, заголовки и, при необходимости, тело запроса.

HTTP-ответ содержит код состояния, заголовки и тело ответа.

Код состояния показывает результат обработки запроса. Например:

- `200 OK` — запрос выполнен успешно;
- `201 Created` — ресурс создан;
- `400 Bad Request` — ошибка в запросе;
- `404 Not Found` — ресурс или маршрут не найден;
- `500 Internal Server Error` — внутренняя ошибка сервера.

## 5. Что такое JSON? Почему он популярен в веб-разработке?

JSON — текстовый формат хранения и передачи структурированных данных. Он популярен благодаря простому синтаксису, небольшому размеру и поддержке большинством языков программирования.

Пример JSON:

```json
{
  "status": "online",
  "connections": 5
}
```

## 6. Как запустить сервер на Node.js?

Обычный запуск сервера:

```bash
node app.js
```

В данной лабораторной работе использовал `nodemon`, поэтому сервер запускался командой:

```bash
npm run dev
```

## 7. Что такое автоматический перезапуск сервера и зачем он нужен?

Автоматический перезапуск позволяет серверу автоматически перезапускаться после изменения исходного кода. Это ускоряет процесс разработки, так как сервер не приходится каждый раз останавливать и запускать вручную.

Для Node.js в данной работе использовался пакет:

```text
nodemon
```

## 8. Какие коды состояния HTTP вы знаете? За что отвечает код 404?

Основные коды состояния:

- `200` — запрос выполнен успешно;
- `201` — ресурс создан;
- `400` — некорректный запрос;
- `401` — требуется авторизация;
- `403` — доступ запрещён;
- `404` — ресурс или маршрут не найден;
- `500` — внутренняя ошибка сервера.

Код `404 Not Found` означает, что сервер был найден, но запрашиваемый ресурс или маршрут отсутствует.

## 9. Что такое middleware в Express?

Middleware — это промежуточная функция, которая выполняется между получением HTTP-запроса и его конечной обработкой.

В работе middleware использовался для логирования:

```javascript
app.use((req, res, next) => {
    console.log(`${new Date().toLocaleString()} ${req.method} ${req.url}`);
    next();
});
```

Вызов `next()` передавал управление следующему обработчику.

## 10. Как получить параметр из URL-пути в Express?

Для создания параметра в пути использовал двоеточие:

```javascript
app.get('/api/orders/:id', ...)
```

Получить значение параметра можно через:

```javascript
req.params.id
```

Например, для адреса:

```text
/api/orders/5
```

значение:

```javascript
req.params.id
```

будет равно `"5"`.
